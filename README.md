# Kemps Academy

Website source, local course content, photography, and Sanity Studio configuration.

## Run locally

1. Install Node.js 20.9 or newer.
2. Run `npm ci`.
3. Copy `.env.example` to `.env.local`.
4. Run `npm run dev` and open http://localhost:3000.

Sanity Studio is available at `/studio`. Sign in with an account that has access to project `jv44cv3g`, dataset `production`, to edit content. Public content can be read without a token; local fallback content is included.

Run `npm run build` for a production build and `npm start` to serve it.

Private credentials, enquiries, dependencies, Git history, and build output are excluded from this archive.
